## 🛠️ Key Projects

### 1. 🚀 VIREN — LLM Cost Optimization Gateway
An OpenAI-compatible gateway that sits between production applications and LLM providers. It dynamically routes and caches prompts to optimize cost without sacrificing quality.
* **GitHub Repository:** [ilay102/LLM](https://github.com/ilay102/LLM)
* **The Impact:**
  * 📉 **87% cost reduction** verified on standard SaaS datasets.
  * ⚖️ **90% factual equivalence** measured via a 3-judge pairwise LLM ensemble.
  * 💻 **100% code-generation pass rate** at **79% lower cost** (verified via execution assertions).
  * ⚡ **<250ms p95 routing overhead** and **26ms p50 semantic cache hits**.
* **Tech Stack:** FastAPI, Redis (RediSearch vector search), SQLite (multi-tenant key hashing & budget caps), Microsoft Presidio (PII redaction), `bge-small` nearest-centroid classifier, Prometheus, Docker.
