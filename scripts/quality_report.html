Using a simple regex pattern to extract the version number:

```python
import re

text = 'Upgraded to v3.14.2 last Tuesday.'

match = re.search(r'v(\d+\.\d+\.\d+)', text)
if match:

```

**How it works:**
| Pattern Part | Meaning |
|---|---|
| `v` | Matches the literal "v" prefix |
| `(\d+\.\d+\.\d+)` | Captures group of digits separated by dots |
| `\d+` | One or more digits |
| `\.` | Escaped literal dot |

The result `match.group(1)` returns just the captured group **without** the `v` prefix. Use `match.group(0)` if you want to include the `v` → `v3.14.2`.

## Python Solution

```python
import re

text = 'Login attempt from 192.168.1.55 at 03:42 UTC.'

# Regex pattern to match an IPv4 address
pattern = r'\b(\d{1,3}\.){3}\d{1,3}\b'

match = re.search(pattern, text)

if match:
    ip_address = match.group()
    print(f"IP Address: {ip_address}")
else:
    print("No IP address found.")
```

---

## Output

```
IP Address: 192.168.1.55
```

---

## How the Regex Works

| Pattern Part | Meaning |
|---|---|
| `\b` | Word boundary (ensures clean match) |
| `\d{1,3}` | Matches 1–3 digits |
| `\.` | Matches a literal dot |
| `(\d{1,3}\.){3}` | Repeats the digit+dot group **3 times** |
| `\d{1,3}` | Matches the final octet |
| `\b` | Closing word boundary |
