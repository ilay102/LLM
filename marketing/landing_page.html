How it works

Three things that compound together. None of them require changing your application code.

01 · Routing

Right model per request

Classifier picks cheap (Haiku / gpt-4o-mini) for easy stuff, balanced (Sonnet) for most things, frontier (Opus) when you actually need it. Tuned on your traffic during the pilot.

02 · Caching

Pay for the same answer twice? No.

Local semantic cache catches identical and paraphrased prompts. Typical SaaS sees 25% cache hit rate. Cached responses cost $0 and return in 3 milliseconds.

03 · Quality proof

Show, don't tell

3-judge pairwise audit splits every disagreement into "factually wrong" vs "stylistic only." Headline = factual rate (the only thing that matters). Per-prompt evidence in the HTML report. We refuse to ship routes that drop factual accuracy.

The integration

Drop this into your app on a dev branch. Mirror runs fire-and-forget. Your prod calls return first, every time.

# Python — with the official OpenAI SDK
from openai import OpenAI
from mirror_python import attach_mirror

client = OpenAI(api_key="sk-...")
attach_mirror(
    client,
    gateway_url="https://gw.your-vpc:8000/v1",
    gateway_key="pilot-xxxxxxxx",
    pilot_id="acme-pilot-1",
)

# Now use client as usual — every call is mirrored.
resp = client.chat.completions.create(model="gpt-4o", messages=[...])
