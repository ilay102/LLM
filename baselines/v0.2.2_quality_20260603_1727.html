Using a simple regex pattern to extract the version number:

```python
import re

text = 'Upgraded to v3.14.2 last Tuesday.'

match = re.search(r'v(\d+\.\d+\.\d+)', text)
if match:

```

### How it works:
| Pattern Part | Meaning |
|---|---|
| `v` | Matches the literal "v" prefix |
| `(\d+\.\d+\.\d+)` | Captures group: one or more digits, dot, digits, dot, digits |
| `.group(1)` | Returns only the captured group (without the "v") |

If you also want to **include the "v"**, simply use `match.group(0)` instead, which would return `v3.14.2`.

Here's a simple way to extract the IP address using Python with **regex**:

## Python Solution

```python
import re

text = 'Login attempt from 192.168.1.55 at 03:42 UTC.'

ip_pattern = r'\b(?:\d{1,3}\.){3}\d{1,3}\b'

match = re.search(ip_pattern, text)

if match:
    ip_address = match.group()
    print(f"IP Address found: {ip_address}")
else:
    print("No IP address found.")
```

## Output
```
IP Address found: 192.168.1.55
```

---

## How the Regex Works

| Pattern Part | Explanation |
|---|---|
| `\b` | Word boundary (ensures clean match) |
| `(?:\d{1,3}\.)` | 1–3 digits followed by a dot |
| `{3}` | Repeated exactly 3 times |
| `\d{1,3}` | Final 1–3 digit octet (no dot) |
| `\b` | Closing word boundary |
