```python
import re

text = 'Login attempt from 192.168.1.55 at 03:42 UTC.'

ip_pattern = r'\b(?:\d{1,3}\.){3}\d{1,3}\b'

match = re.search(ip_pattern, text)

if match:
    ip_address = match.group()
    print(f"IP Address found: {ip_address}")
else:
    print("No IP address found.")
```

## Output
```

```

---

## How the Regex Works

| Pattern Part | Explanation |
|---|---|
| `\b` | Word boundary (ensures clean match) |
| `(?:\d{1,3}\.)` | 1–3 digits followed by a dot |
| `{3}` | Repeated exactly 3 times |
| `\d{1,3}` | Final 1–3 digit octet (no dot) |
| `\b` | Closing word boundary |
